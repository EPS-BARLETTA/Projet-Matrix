🚀 1) Crée ou ouvre ta classe
Hub → Mes classes → Nouvelle évaluation.

📝 2) Configure ta grille
Bouton « Configurer » : crée uniquement tes critères (les champs de base sont facultatifs).
Bouton « Notation » : attribue les points.

👥 3) Organise tes élèves
Utilise la colonne « Groupe » pour :

  • 🧗 Cordées (escalade)
  • 🏓 Terrains (raquettes)
  • 🤝 Équipes (sports co)
  • 👥 Collectif (même numéro pour toute la classe)

🏓 4) Mode Raquettes
• Attribue un terrain initial (1,2,3…)
OU
• Lance une répartition automatique
Puis démarre le défi.

🎯 5) Pendant le défi
• Saisis les scores
• Quand tous les matchs sont renseignés → Rotation suivante
⚠️ Une fois lancé, seul le score modifie le classement.

✅ 6) Statut élève
Un élève est « Évalué » dès que tous ses critères sont remplis (peu importe le niveau atteint).
Absent / dispensé = neutralisé.

💾 7) Sécurité
Pense à exporter (CSV/PDF) ou sauvegarder avant changement d’appareil.

  3. EPS Matrix attribue un identifiant unique pour sécuriser les imports.
  1. Choisis un champ CA1‑CA5 (ou Bloc note) dans la classe.

  3. Active la note /20 si besoin, puis saisis les niveaux directement dans le tableau.
  1. Dans l’évaluation, colonne « Groupe » = terrain actuel (1..20).

  • La colonne « Groupe » te permet d’organiser les élèves selon ta logique pédagogique.

  • Travail collectif : même numéro pour toute la classe
  • Le groupe ne modifie pas la note.
  • Il sert uniquement à structurer l’organisation.
  • En mode terrain, le groupe correspond automatiquement au terrain actif.
